These four newer skills extend the eight core jobs: results-chain alignment, sampling plans, data quality planning and baseline planning. They were checked in Claude Code on ordinary, incomplete and unsuitable inputs. Checked in Claude Code. Anthropic's help page says Free and paid plans can use uploaded skills once code execution is turned on; we checked browser upload on a paid plan only. Practitioner feedback is still being gathered.

Open each skill's START.md for minimum inputs and a starter. examples/input.md, incomplete.md and unsuitable.md are fictional teaching cases; output.md is a manually authored illustration, not a generated or accepted test result. Templates are included where useful. Each SKILL.md is the maintained method; compatibility commands and legacy domains route to it.

Use explicit readable files or a scoped folder in Code. In a browser, readable attachments replace folder access. Individual skill ZIPs are candidates for custom-skill upload, while SKILL.md can be pasted as a candidate fallback; neither browser route is verified. A workspace plugin ZIP is a Code snapshot, not a browser skill. Preserve the actual saved Markdown, original inputs and a handover when pausing. Word/PDF/spreadsheet outputs are not advertised.

The offering requires no site signup or paid API backend. It does not provide a Claude account, waive provider usage limits or guarantee completion within a Free-plan allowance. The first eight skills are described in PILOT-START.md; their checks do not carry over to these four. Confirm current access for the intended account and route before relying on them.
