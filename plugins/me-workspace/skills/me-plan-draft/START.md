# Start: M&E plan draft

Use this skill to draft an operational monitoring and evaluation plan that connects results, indicators, methods, data quality, roles, learning, and use. The draft needs program-team review before adoption.

**Intake:** attach files or name one folder. For folder intake, ask the assistant to list the files it proposes to use. The assistant must state the intake mode.

**Starter:**

> Use me-plan-draft on the attached files [or folder: path]. Draft an operational M&E plan using the eleven components below. Link facts to source evidence, preserve approved indicators and targets, and mark assumptions, proposals, and decisions required. Do not invent budget, owners, frequencies, or commitments.

Examples are fictional illustrations. They are not live test evidence.
