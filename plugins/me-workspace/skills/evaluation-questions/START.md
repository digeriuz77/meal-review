# Start: Evaluation question design

Use this skill when you need an evaluation question set tied to decisions and feasible evidence. It creates an editable Markdown draft. Questions remain provisional until the evaluation commissioner confirms their use and scope.

**Intake:** either attach the source files in chat, or name one folder for review. For folder intake, the assistant should list candidate files and use only the ones you identify. It must say which intake mode it used.

**Starter:**

> Use the evaluation-questions skill on the attached files [or the files in: folder path]. Draft a prioritized question set for [evaluation purpose]. The decisions or intended uses are [known uses, or “not yet specified”]. Preserve source evidence references, mark assumptions and open decisions, and return an editable Markdown artifact.

See `examples/` for normal, incomplete, unsuitable, and illustrative output examples. The output example is fictional and shows the expected shape, not evidence of a live run.
