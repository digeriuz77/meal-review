# Start: Indicator reference sheets

Use this skill to document indicators consistently, including definitions, calculations, data sources, collection tools, frequency, roles, quality checks, and use. It preserves supplied approved values and marks missing fields.

**Intake:** attach files or name a folder and ask the assistant to list candidate files before it uses them. The assistant states the intake mode and files selected.

**Starter:**

> Use indicator-reference-sheets on the attached files [or folder: path]. Create one editable reference sheet per supplied indicator. Preserve existing approved wording and values, cite source evidence, and mark missing fields “Not supplied” or “Decision required.” Do not invent targets, owners, frequencies, or sources.

See `template.md` for the editable field set and `examples/` for fictional examples. Example outputs illustrate format only.
