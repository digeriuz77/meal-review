# Start: Evaluation TOR draft

Use this skill to create an evidence-linked draft Terms of Reference for an evaluation. It fills a ten-section structure and marks missing decisions. A commissioner and technical reviewers still need to approve the document.

**Intake:** attach source files, or name a folder and have the assistant list files before selecting them. It must state whether it used uploads or folder intake.

**Starter:**

> Use evaluation-tor-draft with the attached files [or folder: path]. Draft a source-linked evaluation TOR using the ten-section structure. Preserve unknowns as placeholders, distinguish facts from assumptions and proposals, and flag design or ethics decisions that require the commissioning team. Return editable Markdown.

See `examples/` for normal, incomplete, unsuitable, and illustrative output examples. The sample TOR excerpt is fictional and is not a live test result.
