# Start: Measurement feasibility

Use this skill to identify which measurement demands fit documented data, staff, timing, and resources, and where more information is needed. It calculates workload only from supplied volumes and time assumptions.

**Intake:** attach source files, or name a folder and ask the assistant to list candidates before selecting them. The assistant states which intake mode it used.

**Starter:**

> Use measurement-feasibility on the attached files [or folder: path]. Assess each stated measurement requirement against documented sources, staff, timing, frequency, and resources. Calculate workload only from supplied volumes and time assumptions. Separate evidence from design estimates and propose options without silently removing requirements.

Examples are fictional illustrations, not live test evidence.
