# Start: Question and method alignment

Use this skill to map evaluation questions to evidence, data sources, collection methods, and limitations. It returns an editable matrix; it does not finalize sampling or claim causal impact.

**Intake:** attach files directly, or name a folder and ask the assistant to list candidate files before selecting them. The assistant must state which mode it used.

**Starter:**

> Use question-method-alignment on the attached files [or folder: path]. Map each evaluation question to the evidence needed, sources, collection methods, and limitations. Use only supplied facts; flag unknown sample size, access, timing, cost, or permissions. Return an editable Markdown matrix.

See `examples/` for normal, incomplete, unsuitable, and illustrative output examples. Examples are fictional and not live test evidence.
