# Start: Progress evidence and trends

Use this skill to check what a progress report supports, whether expected indicators are covered, and whether period comparisons are valid. With one period only, it checks evidence and coverage but will not call results a trend.

**Intake:** attach reports, or name a folder and ask the assistant to list candidate files first. It must state the intake mode and files used.

**Starter:**

> Use progress-evidence on the attached files [or folder: path]. Check indicator coverage and evidence, and compare periods only when definitions, cohorts, denominators, and periods are comparable. Keep the exact headings Critical Issues, Important Issues, and Minor Improvements. Mark single-period analysis as not a trend assessment.

Examples are fictional and illustrate output shape only.
